# Зафиксированные версии для образа сервиса (профиль `service`).
#
# Зачем. В `pyproject.toml` стоят нижние границы («fastapi>=0.110») — так и
# должно быть у библиотеки, которую ставят рядом с чужими зависимостями. Но
# образ собирается из тех же строк, и это значит, что две сборки одного
# коммита, разнесённые на неделю, содержат разный код: подтянулась новая
# транзитивная версия, и воспроизвести вчерашний образ уже нечем. Для продукта,
# который ставят внутрь чужого периметра, это не мелочь: «у нас не работает» и
# «у нас работает» перестают быть сравнимыми.
#
# Здесь — полный список, включая транзитивные. Файл передаётся установке через
# `-c`, то есть он ОГРАНИЧИВАЕТ версии, а не задаёт список пакетов: что ставить,
# по-прежнему решает `pyproject.toml`.
#
# Обновление — осознанное действие, а не побочный эффект сборки:
#
#   pip install "vistest[server]" --upgrade --dry-run     # посмотреть, что новее
#   pip freeze > constraints-service.txt                   # в чистом venv
#
# Профили `browser`, `ai` и `report` сюда не входят: playwright прибит к версии
# браузера в образе (см. комментарий в pyproject), а onnxruntime и allure ставят
# те, кому они нужны.
